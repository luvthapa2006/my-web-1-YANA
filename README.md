# YANA - You Are Not Alone

**YANA (You Are Not Alone)** is a horror-themed interactive chat application that immerses users in a creepy atmosphere with eerie visuals, unsettling sound effects, and hauntingly intelligent responses. This project is built using HTML, CSS, and JavaScript and is designed for personal or educational use.

---

## 🎃 Features

* **Splash Screen** with horror animation
* **Home Screen** with animated SVG eyes and blood effects
* **Interactive Chat Screen** with AI-generated horror responses
* **Eye Tracking** using cursor movement
* **Audio Effects** including whispers and eerie background music
* **Modal Popups** for About and License information
* **Fully Responsive** layout for all screen sizes

---

## 📁 Project Structure

```bash
├── index.html     # Main HTML file containing all UI elements
├── style.css      # CSS file with custom horror styles and animations
├── script.js      # JavaScript file for screen control, chat AI, and effects
```

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/yana-horror-chat.git
cd yana-horror-chat
```

### 2. Run the App

Simply open `index.html` in any modern web browser.

> ⚠️ This app is intended for users aged **18 and above** due to its horror content.
